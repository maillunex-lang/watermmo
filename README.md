# WaterMMO 0.1.0

Стартовый офлайн-каркас морской MMORPG для Android на Godot 4.7.2.

- Главное меню с морской стилистикой.
- Тестовый архипелаг с кораблём, которым можно управлять касанием.
- Панели «Порт», «Карта», «Флот» и «Задания» пока информационные.
- Сетевой MMO-сервер и игровые механики будут добавлены последовательно.

Запуск: открыть `project.godot` в Godot 4.7.2 и нажать F5.
